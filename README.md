# 보글사다리3 V7.2 Binary480 Rolling

V7의 이진 분석법은 그대로 두고 분석 범위만 최근 최대 480회로 확장한 독립판입니다.

## 분석
- 좌/우, 3줄/4줄, 홀/짝을 각각 이진 차원으로 분해
- 각 차원에서 최근 3·4·5·6 완전 동일패턴 검색
- 각 패턴 길이는 동일 1표
- 동률은 기권
- 최대 12표를 4개 유효조합에 대입해 가장 많이 충돌하는 1개 제외
- 가중치 없음 / Hedge 없음 / Binary 2-Bit 추가 없음

## 데이터 범위
공개 API 한 번 호출이 최근 스냅샷만 제공하므로, 설치 직후에는 약 30회부터 시작합니다.
매 회차 API 스냅샷을 받아 idx 중복을 제거해 합치고 최근 최대 480회만 저장합니다.
따라서 30 → 31 → 32 ... → 480까지 누적된 뒤에는 항상 최신 최대480회 Rolling으로 유지됩니다.

기존 분석기의 history JSON을 가져올 수 있으면 초기 480회 확보를 더 빠르게 할 수 있습니다.

## 초기화
'성적만 초기화'는 승패/수익만 지우고 Rolling480 분석 history는 보존합니다.

균등·독립 무작위라면 삼치기 기준 성공률은 75%입니다.

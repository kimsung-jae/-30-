# 보글사다리3 V7 Binary30 Snapshot

이 버전은 V4.2의 3차원 이진분해 방식만 남기고 분석 history를 API 최신30회로 고정한 실험판입니다.

- 매 조회마다 API 최신 최대30회를 새로 받음
- 이전 스냅샷과 merge하지 않음
- 31회, 50회, 480회로 누적되지 않음
- 좌/우: 좌=+1, 우=-1
- 사다리수: 3줄=+1, 4줄=-1
- 홀/짝: 홀=+1, 짝=-1
- 각 차원에서 최근3/4/5/6 완전 동일패턴을 그 30회 안에서만 찾음
- 각 길이는 동일 1표, 동률은 기권
- 최대 12표를 4개 유효조합에 대입해 가장 많이 충돌하는 1개 제외
- 학습 가중치/Hedge/과거 누적/유사패턴 없음
- 실전 승패·수익은 계속 누적되지만 분석에는 절대 사용하지 않음
- 성적 초기화는 실전성적만 지우고 API30 스냅샷은 보존

균등·독립 무작위라면 삼치기 기준 성공률은 75%입니다.
